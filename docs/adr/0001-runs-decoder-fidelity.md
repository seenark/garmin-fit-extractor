# Runs decoder ต้องรักษา identity และ native representation

คง Axum API และใช้ Rust `fitparser` 0.11.0 พร้อม minimal maintained MIT vendor patch เป็น decoder ของ Runs ไม่ rewrite backend เพื่อเปลี่ยนภาษา Public seam มีเพียง `fit::runs::decode_run_to_writer` ซึ่งเขียน decoded archive, normalized Running Session และ preserved legacy projection โดยใช้ normalizer ชุดเดียว ไม่ materialize whole archive ตัว archive รักษา numeric/native/developer identity, ordered definitions/messages/fields, source byte references และ original composite โดยเปิด `KeepCompositeFields`, `PreserveInvalidValues`, `PreserveUnknownDeveloperFields` ไม่เปิด combined numeric-enum mode ที่ทำ developer metadata ล้ม

General component extraction หยุดเมื่อ encoded bits ไม่ครบ และ accumulated target ใช้ native anchor กับ rollover carry จริง ไม่กรอง zero หลัง decode Root regression ล้มก่อน patch แล้วผ่านพร้อม public Runs tests ที่พิสูจน์ 3-byte packed HR สอง events, native/developer collisions, invalid/absent/ordinary zero, exact unsafe integers และ compressed timestamps Corpus สังเคราะห์ CC0 มี generator/license/manifest ที่เก็บถาวรใน `apps/api/tests/fixtures/runs/`

Actual decode CLI smoke ผ่าน Garmin single-session และ source-backed packed RR รวม progressive fixture 1,063 intervals ที่มี timestamp/fractional/event-counter anchor จริงพร้อม numeric source references Native HRV arrival ยัง unanchored และไม่สร้าง RR จาก sampled HR ผล software correctness ไม่ใช่ physiological validation หรือ release-budget proof ดูรายละเอียดคำสั่งและ observed output ใน [decoder assessment](../runs-rebuild/decoder-assessment.md)

เลือก typed streaming หลัง actual 100,000-record whole-Value path ใช้ max RSS 9.89 GB และแม้ลบ duplicated extensions แล้วยังใช้ 4.11 GB Writer ใหม่เขียน decoded messages ตรงลง caller-owned private `run.json` เก็บ typed metrics/source references ใน memory และ spool เฉพาะ arrays ที่จำเป็นภายใต้ 0700/0600 พร้อม shared hard disk bound 512 MiB ทั้ง temporary writes/final output Parent ใช้ `runs-spool-1` stdout control ไม่เกิน 64 KiB ตรวจ fixed filename/no symlink/byte length/SHA/source hash และ stage chunks 64 KiB ไม่ขยาย stdout limit หรือ truncate source values Actual Darwin debug smoke ให้ 496,794,368 bytes, 42.77 s และ max RSS 230,719,488 bytes พร้อมครบ 100,000 samples ส่วน Linux 512 MiB address-space/60 s gate ต้องพิสูจน์ใน production subprocess แยกต่างหาก

เปิด `serde_json/float_roundtrip` เพราะ RR JSON spool ต้องไม่เปลี่ยน native fractional timestamp การทดสอบด้วย encoded fraction 9/32768 พบ one-ULP error ก่อนแก้ แล้วตรวจ exact timestamp/elapsed ผ่านหลังแก้ Public `fit::runs::decoder_metadata()` เป็น definition ร่วมสำหรับ archive/revision/export metadata และเก็บ library/profile/options/schema/normalizer identifiers พร้อม actual source hashes ห้าชุด ไม่ invent metadata จากชื่อ implementation เดิม Source hashes แยกจาก private uploaded FIT checksum และต้องปรับตาม source ที่เปลี่ยน

Python `fitdecode` 0.11.0 เป็น MIT frame-level comparator และทางเลือกเมื่อ Rust archive gate ไม่ผ่าน; official Python/JS SDK ไม่เป็น decoder เดี่ยวโดยอัตโนมัติ เพราะ compressed timestamps/unknown defaults และ FIT Protocol License ต้องตรวจเพิ่มเติม การค้นพบ license §2(f) กั้น official SDK comparative benchmark/publication เพิ่ม ไม่ใช่ permission ที่ให้จากการมี package อยู่เดิม

Original FIT retention ทำให้ decode ใหม่ได้ แต่ไม่ทำให้ semantic gaps เป็นงานเสร็จ ค่า raw encoded/offset ที่อ่านไม่ได้ต้องมี warning ไม่แต่ง metadata หรืออ้าง 100% extraction Library ยังไม่เปิด subfield reference predicates และ later developer descriptions ไม่ทำให้ opaque values ก่อนหน้านั้นกลายเป็น interpreted metrics อัตโนมัติ Runs seam รับ declared header sizeขั้นต่ำ12 bytes และ skip future header extensionแบบopaque โดยยังตรวจ optional header CRCที่fixed bytes12–13/first12 bytes และ final file CRCที่รวมextensions ตาม [FIT Protocol](https://developer.garmin.com/fit/articles/fit-protocol/fit_protocol.html#fileheader) Reject truncated headers/size mismatch/trailing/chained files Callerต้องทิ้ง private partial outputเมื่อ integrity/semantic/resource validationล้ม และตั้ง child `TMPDIR` ภายใน caller-owned directoryเพื่อ cleanup forced termination Production subprocess budgets, HTTP/store/export/privacy round-trip และ physiological reference validationยังเป็น release gatesตาม [decoder assessment](../runs-rebuild/decoder-assessment.md) และ DEC-08–10/ARCH-01 รูปแบบsubprocessไม่เปิด network serviceใหม่
